# Code of Conduct

## The short version

Be decent. Assume the other person is acting in good faith. Criticise code and ideas, not people.

## What we expect

- **Assume competence.** Someone asking a basic question may be an expert in a different field. Someone reporting a bug you cannot reproduce is not lying.
- **Be specific.** "This is wrong" helps nobody. "This violates RFC 4918 §10.4.2 because …" helps everyone, including the person who wrote it.
- **Disagree openly and without heat.** Technical disagreement is how the project gets better. It stops being useful the moment it becomes personal.
- **Accept that you might be wrong.** Including us. Especially about protocol behaviour, where the specification usually settles it.

## What is not acceptable

Harassment, personal attacks, demeaning remarks about someone's background or identity, deliberate intimidation, and sustained disruption of discussion.

Publishing someone's private information without permission.

Treating a maintainer's unpaid time as an entitlement. Nobody here owes anybody a response on a schedule.

## Scope

This applies to issues, pull requests, commit messages, code comments and any other project space, and to public spaces when representing the project.

## Reporting

Write to **conduct@dav.services**. Reports are handled confidentially by the maintainers. If a report concerns a maintainer, it will be handled by the others.

We will respond within a week, and we will tell you what we did.

## Consequences

Depending on severity: a private word, a public correction, temporary exclusion from a discussion, or a permanent ban. We will explain the reason in each case.

## Attribution

This is a deliberately short document. It is not adapted from a standard template, because a code of conduct nobody reads protects nobody.
